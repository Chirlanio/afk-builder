# Sugestões de Melhoria - AFK Builder

Este documento lista as melhorias estratégicas propostas para elevar o AFK Builder ao próximo patamar de utilidade para a comunidade de AFK Arena.

## 1. Importação de Roster via OCR (Screenshot) ✅
*   **Status:** Implementado (Fase 34).
*   **Descrição:** Redução drástica do atrito de entrada de dados permitindo o upload de prints do jogo para atualizar o nível e a identidade dos heróis no roster através de reconhecimento óptico de caracteres (Tesseract.js).

## 2. Builder de Coleções (Galeria Tenebrosa)
*   **Objetivo:** Desmistificar o sistema de Coleções (Ghoulish Gallery), que é altamente complexo e baseado em RNG.
*   **Funcionalidades:**
    *   Simulador de montagem de Coleções ideais.
    *   Sugestão de heróis do roster do usuário que melhor se beneficiam de determinados stats (ATK, Crit, Control Duration, etc.).
    *   Guia de "Best-in-Slot" para cada herói.

## 3. Módulo de Abyssal Expedition (AE)
*   **Objetivo:** Transformar o app em uma ferramenta essencial para guildas durante o maior evento do jogo.
*   **Funcionalidades:**
    *   Planejador de caminho em tiles.
    *   Calculadora de dano em chefes baseada em relíquias (relics) e heróis disponíveis.
    *   Sistema de gestão de stamina para otimizar ataques de membros da guilda.

## 4. Inteligência de "Counters" (Contra-ataques)
*   **Objetivo:** Ajudar o jogador a vencer no PvP (Arena) e em estágios de campanha difíceis.
*   **Funcionalidades:**
    *   Base de dados de heróis e suas contrapartes (ex: heróis que anulam healers, heróis que puxam a backline).
    *   No editor de formações, ao identificar a equipe inimiga, sugerir heróis de contra-ataque do roster do usuário.

## 5. Camada Social e "Global Tier List"
*   **Objetivo:** Criar retenção e transformar a ferramenta em um hub comunitário.
*   **Funcionalidades:**
    *   **Global Tier List:** Agregação automática dos dados de todos os usuários para mostrar quem são os heróis mais investidos e melhor avaliados pela comunidade.
    *   **Sistema de Votação:** Curtidas e comentários em formações compartilhadas.
    *   **Guildas in-app:** Espaço para compartilhar rosters entre membros da mesma guilda para facilitar o planejamento de AE ou formações de defesa.
